# Lythwain — Visual Development

**Development state:** Active exploration; no approved master reference yet.

Store retained Lythwain artwork directly in this directory with descriptive, stable filenames. Record each image's status here rather than moving it among status subdirectories.

Preserve current working visual development and meaningful alternatives. Do not silently replace an existing working Lythwain design merely because a new variation is explored.

## Retained artwork

### `lythwain-df-armor-exploration.png`
**Status:** Exploration

D/F armor comparison used to establish Lythwain's ranger armor direction. DF-3 became the preferred overall direction, with fully covered arms/wrists required in subsequent development.

### `lythwain-df3-ranger-armor-working-reference.png`
**Status:** Current working reference

Current overall visual direction for Lythwain's ranger equipment: DF-3-derived studded leather armor, full arm/wrist coverage, and recurve bow. The hairstyle shown is not authoritative; Lythwain's intended blond hair is swept completely back from the forehead and temples into a low ponytail with no loose face-framing strands.

### `lythwain-swept-back-hair-placement-study.png`
**Status:** Exploration — detail reference only

Retained specifically to document the intended swept-back hair placement. The face and rendering/art style in this image were rejected and must not be used as Lythwain's facial or stylistic reference.

### `lythwain-wakizashi-rune-blade-study.png`
**Status:** Exploration — blade/rune reference

Retained for the approved visual distinction between the flowing Elven rune treatment and angular Dwarven rune treatment. The matched-hilt concept shown in this study was superseded; each weapon is intended to be individually designed.

### `lythwain-elven-dwarven-wakizashi-working-reference.png`
**Status:** Current working reference

Current weapon-design direction. Lythwain carries two individually designed wakizashi: one bearing Elven runes and one bearing Dwarven runes. Their differing hilt designs make each weapon visually unique, while their ornate scabbards are elven-made. Final scabbard placement/carry geometry remains unresolved.

## Current visual cautions

- No image in this directory is an Approved Master Reference yet.
- Preserve the established Elarindor/Vaelyn-compatible illustration style in future character work; several discarded generations drifted toward semi-photorealistic RPG portraiture.
- Do not treat generated loose hair strands as intentional. Lythwain's hair is blond and pulled fully back, leaving the face clear.
- Lythwain's current ranged weapon direction is a recurve bow.
- Lythwain's arms and wrists should remain covered in his ranger outfit.
