# Vaelyn — Visual Development

**Development state:** Active rewrite/redevelopment.

Store retained Vaelyn artwork directly in this directory with descriptive, stable filenames. Record each image's status here rather than moving it among status subdirectories.

Older Vaelyn artwork must not be mistaken for automatically current material. Preserve useful older versions for comparison until James deliberately approves, supersedes, rejects, archives, or requests deletion of them. New candidates should remain clearly distinguishable from older/historical references while Vaelyn's redesign is active.

When assets are added, list each retained image here with its status (`Exploration`, `Current working reference`, `Approved master reference`, `Superseded`, or `Rejected`) and a short note explaining what visual decisions it represents.
