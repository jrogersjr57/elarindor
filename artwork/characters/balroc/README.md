# Balroc — Visual Development

**Development state:** Active exploration. Current visual identity is established enough for continuity, but no image is an approved master reference yet.

Store retained Balroc artwork directly in this directory with descriptive, stable filenames. Record each image's status here rather than moving it among status subdirectories. Exploration-only assets may be retained under `exploration/` when they document a meaningful visual decision.

Preserve current working visual development and meaningful alternatives. Do not silently replace an existing working Balroc design merely because a new variation is explored.

## Retained artwork

### `balroc-current-character-reference.png`
**Status:** Current working reference

Primary full-character visual reference. Establishes Balroc's current overall appearance: stout dwarf proportions; seasoned, battle-hardened face; fire-orange hair; elaborate braided hair and beard with engraved metal cuffs; heavy downward moustache integrated into the beard; amber eyes; prominent scar crossing the right eye without impairing vision; mobile front-line armor; red patterned front sash/tabard; two-handed double-bladed battle axe; and crossbow as his secondary ranged weapon.

This image is a working reference, not immutable canon. Personality, demeanor, poses, and additional details remain under exploration.

### `balroc-head-reference.png`
**Status:** Current working reference

Head/hair/beard reference retained for facial continuity. Use it especially for the established braid arrangement, metal braid cuffs, moustache structure, fire-orange hair direction, and right-eye scar. Where it conflicts with later decisions, `balroc-current-character-reference.png` takes precedence; amber is the selected eye color.

### `exploration/balroc-eye-color-exploration.png`
**Status:** Exploration — decision resolved

Comparison study of amber, green, steel gray, hazel, and black eyes. Retained as visual-development provenance. **Amber was selected** for Balroc; the scarred right eye remains functional and the same healthy amber as the left.
