# Elarindor Group Artwork

This directory stores artwork featuring multiple recurring characters together, including group compositions, party lineups, height/proportion comparisons, and other multi-character visual references.

## Status organization

- `exploration/` — viable group compositions, scale experiments, and visual alternatives still under consideration.
- `current/` — best current working group references when a composition or comparison becomes important to ongoing development.
- `archive/` — superseded or rejected group artwork retained for historical comparison.

The first planned exploration asset is `elarindor-quartet-balanced-stature.png`, a Vaelyn/Toma/Lythwain/Balroc stature and lineup exploration.
