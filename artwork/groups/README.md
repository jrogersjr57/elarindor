# Elarindor Group Artwork

This directory stores artwork featuring multiple recurring characters together, including group compositions, party lineups, height/proportion comparisons, and other multi-character visual references.

Artwork remains directly in this directory. Its development status is recorded here and, when useful, in the corresponding Notion documentation. A status change does not require moving the image to another folder.

## Retained assets

### `elarindor-quartet-balanced-stature.png`

- **Status:** Exploration
- **Characters:** Vaelyn, Toma, Lythwain, Balroc
- **Purpose:** Four-character lineup and stature/proportion exploration created while reconsidering the relative heights and visual separation of the current party.
- **Continuity use:** Useful for comparing the experimental relationship among the four characters, but it is not an approved master reference and should not by itself establish final heights, faces, costumes, or other canon visual details.

## Maintenance

When a group image becomes the current working reference, is approved, superseded, or rejected, update its status and notes here rather than moving the file solely because its status changed. Retain meaningful historical comparisons unless James deliberately requests deletion.
