# Valdari — Visual Development

This directory stores species-level visual references for the Valdari. These assets support visual continuity and image-generation control; their presence in GitHub does **not** make every depicted detail canon.

Use the repository artwork status model: `Exploration`, `Current working reference`, `Approved master reference`, `Superseded`, or `Rejected`.

## Current working reference

- `valdari_ear_anatomy_guide.png` — **Current working reference.** Preferred generator-facing control sheet for Valdari ear anatomy. It supports the approved written anatomy in the Valdari Race Bible: a fundamentally human-like ear with only a subtle species-specific modification concentrated in the upper portion.

  **Controlling ear-shape guidance:**
  - human-like base anatomy and recognizable inner-ear organization;
  - only slightly longer than a typical human ear;
  - upper rim / helix flows gently backward in a shallow, windswept arc;
  - terminal shape remains softly rounded, never a sharp point;
  - from the front, the ear should read almost human;
  - the backward sweep becomes clearer at three-quarter view and most evident in profile;
  - avoid long triangular elf silhouettes, exaggerated horizontal extension, and standard pointed fantasy ears.

  **Scope limitation:** this image is a visual-control reference for Valdari ear anatomy only. The depicted face, hair, clothing, pigmentation, jewelry, environment, typography, decorative elements, and generated lore text are not automatically authoritative for Vaelyn or for the Valdari population.

## Superseded / historical reference

- `valdari-ear-design-historical-reference.png` — **Superseded.** Earlier Valdari ear-design sheet preserved as development history and comparison evidence. Although its written intent moved toward a softer non-elven ear, the pictured ears remain more elongated, triangular, and elf-adjacent than the current approved direction. Do not use it as the primary generator-control reference when the current guide is available.

## Continuity rule

For new Valdari character or scene generation where ears are materially visible, use the current written anatomy together with `valdari_ear_anatomy_guide.png`. The new guide supersedes the older sheet for ear-shape control, but does not supersede unrelated character-specific or species-level references outside its stated scope.
